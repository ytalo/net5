# net5

Repositorio de pruebas y proyectos en .NET / C#.

| Proyecto | Descripción |
|---|---|
| [`Video2BIC/`](Video2BIC/) | Lee una secuencia de vídeo, detecta contenedores marítimos y les identifica el código BIC (ISO 6346): OCR sobre el panel, validación del dígito de control y votación entre fotogramas. Reutiliza la detección y el seguimiento de `MaritimeVision`. |
| [`MaritimeVision/`](MaritimeVision/) | Detección y seguimiento de contenedores marítimos en vídeo con YOLO (ONNX Runtime) y ByteTrack. Incluye CLI, visor web y biblioteca reutilizable. |
| `SimpleWebAPI/` | API web mínima de ejemplo. |
| `net5consola1/` | Aplicación de consola de ejemplo. |
